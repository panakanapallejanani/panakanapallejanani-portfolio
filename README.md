# Janani Portfolio — Vercel Ready

## Run locally
1. Extract this ZIP.
2. Open the extracted `janani_portfolio_vercel` folder in VS Code.
3. Open `index.html` in a browser (or use the VS Code Live Server extension).

## Deploy to Vercel
1. Create a GitHub repository and upload all three files: `index.html`, `styles.css`, `script.js`.
2. In Vercel, choose **Add New → Project** and import that GitHub repository.
3. Framework Preset: **Other**.
4. Build Command: leave blank.
5. Output Directory: leave blank (or `.` if Vercel requires a value).
6. Click **Deploy**.

## Before publishing
- Add your actual LinkedIn and GitHub URLs in the contact section.
- Add a resume PDF link if you want a Download Resume button.
- Verify all dates, project details, contact details, and certifications.
- The project preview graphics are CSS illustrations, not screenshots of your actual applications.
